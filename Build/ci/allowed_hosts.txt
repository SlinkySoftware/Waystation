# tests/clients/harness/check_fixtures.py). The repository is public: only documentation names and public upstream
# services belong here, never a real deployment's hosts.
#
# A plain entry allows the name itself and every subdomain. Internal-only suffixes (.local, .lan, .internal, .corp,
# .home, .private, ...) are always rejected; reserved names (*.example, *.test, *.invalid, *.localhost) are always
# allowed. A format can add public hosts that appear in its upstream content in tests/clients/<format>/allowed_hosts.txt
# (applies to tests/clients/<format>/ and tests/fixtures/upstreams/<format>/ only).
#
#   url <prefix>         allows one exact URL prefix without allowing its host anywhere else (source control)
#   not-a-host <token>   an exact dotted token that is code, not a host name (i18n keys, event names)
#
# Adding an entry is a reviewed change: say why in a comment.
