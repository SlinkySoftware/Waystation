# Waystation data model

MongoDB is the system of record; Valkey holds only ephemeral state; the blob store holds file content.
Collection access goes through the `*.db` modules only (ARCHITECTURE §3). IDs are ULIDs (string) unless noted.
All timestamps are UTC `datetime`. Collections and indexes are declared in `waystation_common.db.collections` and
created by `init` (`db.schema.ensure_schema`, idempotent; index names are part of the schema); data changes are
forward-only migrations (`db.migrations`, recorded in `migrations`).

| `upstream:<repo_id>:ratelimit` | hash | last seen upstream rate-limit headers |
| `uptok:<sha256(repository key, scope)[:40]>` | string `<expiry epoch ms> <AES-GCM token>` (PX = remaining lifetime, ≤ 1 h) | a docker proxy's upstream registry token, shared by every server process; encrypted with `SECRET_KEYS` (aad = `docker-upstream-token:` + the key), never stored without secret keys (FORMATS docker, T-P2-DOCKERP) |
| `uprealm:<sha256(repository key)[:40]>` | string JSON (`{url, service}`, `"basic"` or `"none"`), TTL 1 h | the challenge a docker proxy's upstream `/v2/` answered, shared by every server process |
| `docker:noreferrers:<repo_id>:<config_version>` | string `1`, TTL 1 h | the docker proxy's upstream has no referrers API (it answered 404): referrers lookups go straight to the `sha256-<hex>` tag schema |
| `regtok:nbf:<user id>` | string epoch ms, TTL 6 min | the user's registry-token cut-off (`users.tokens_not_before`), read on every `/v2/` request with a user's registry token so a revocation reaches every replica at once (T-S12) |

## 3. Blob store (`WAYSTATION_DATA_DIR`)
See ARCHITECTURE §5. `blobs/sha256/aa/bb/<hex>`, `uploads/<uuid>`, `keys/<repo id>.json` (signing keys, `waystation_common.signing`), `keys/registry-token.key` (the Docker registry token signing key; both re-encrypted, never changed, by `secrets.rotate`: `waystation_common.keyfiles`). Nothing else is written there. A Helm group's merged `index.yaml` is a blob no asset references (served by X-Accel through an in-process pointer, re-committed when its members change and claimed against GC again every hour while served); blob GC removes old merges after the grace period.
