# Instructions for AI agents

- **Deploying, installing, upgrading or operating Waystation** in someone's environment (a home lab, a NAS, a
  server): follow [`Documents/Operations/AGENT_DEPLOYMENT.md`](Documents/Operations/AGENT_DEPLOYMENT.md). Use the
  released images (`ghcr.io/slinkysoftware/waystation-{server,worker,web}:<version>`); you do not need to build or
  test the code.
- **Working on the code** (features, fixes, docs in this repository): follow [`CLAUDE.md`](CLAUDE.md), which applies
  to every coding agent, not only Claude.
